# Portfolio - MUHAMMAD AL FARID

Simple personal portfolio built with HTML5, CSS3, and Vanilla JavaScript.

Features

- Minimal, modern, and responsive design
- Sticky navigation with mobile hamburger
- Smooth scrolling and scroll reveal
- Skills with progress bars
- Projects section with placeholder links
- Contact form validation (no backend)
- Dark mode toggle and back-to-top button

Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

Project structure

```
portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── profile.jpg (add your photo)
    ├── profile.svg
    └── project/
```

How to run

1. Open `index.html` in your browser. No build step required.

Git & Deploy (GitHub)

1. Initialize repo:

```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/USERNAME/portfolio.git
git push -u origin main
```

2. Enable GitHub Pages:

- Go to your repository on GitHub → Settings → Pages
- Under "Source", choose branch `main` and folder `/ (root)`
- Save; your site will be published at `https://USERNAME.github.io/portfolio/`

Notes

- Replace placeholder links and `assets/profile.jpg` with your own images and URLs.
- This project intentionally avoids frameworks to keep it lightweight and educational.
